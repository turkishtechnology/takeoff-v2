# SVG sprite

`@takeoff-icons/sprite` ships a single `sprite.svg` containing every icon as a
`<symbol>`. Reference icons with `<use>` — one network request for the whole
set, no per-icon JavaScript.

```bash
pnpm add @takeoff-icons/sprite
```

## Symbol IDs

Each symbol is keyed `ti-<name>-<style>-<type>`:

```
ti-add-outlined-rounded
ti-alert-filled-sharp
ti-account-circle-outlined-bevel
```

## Using an icon

Point `<use>` at the sprite URL plus the symbol ID:

```html
<svg width="24" height="24">
  <use href="/path/to/sprite.svg#ti-add-outlined-rounded" />
</svg>
```

Resolve the sprite URL with your bundler if you prefer importing it:

```ts
import spriteUrl from '@takeoff-icons/sprite';

// `${spriteUrl}#ti-add-outlined-rounded`
```

## Sizing & color

The symbols use `fill="currentColor"`, so a referenced icon inherits the `color`
of the host `<svg>` and sizes with its `width`/`height`:

```html
<svg width="32" height="32" style="color: #c8102e">
  <use href="/path/to/sprite.svg#ti-alert-filled-rounded" />
</svg>
```
