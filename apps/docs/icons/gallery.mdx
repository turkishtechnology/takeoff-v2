# Icon Gallery

Search, filter by category, switch variants, and click any icon to open its
usage dialog — copy the install command, import, and usage snippet for React,
the icon font, or the raw SVG. The gallery is generated from
`@takeoff-icons/core` metadata — run `pnpm --filter docs gen:icons` after adding
or removing icons.
