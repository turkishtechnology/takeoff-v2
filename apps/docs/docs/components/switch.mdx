# Switch

`Switch` lets users turn a single setting on or off, especially for preferences,
permissions, and form options. Takeoff visual props stay on the wrapper while
Spar owns checked state, forms, focus, and keyboard behavior.

## Usage

```tsx
import { Switch, Field } from '@takeoff-ui/react-spar';
```

```tsx
<Field>
  <Field.Label />
  <Switch>
    <Switch.Control>
      <Switch.Track>
        <Switch.Thumb />
      </Switch.Track>
    </Switch.Control>
  </Switch>
  <Field.Description />
</Field>
```

## Accessibility & Keyboard

- `Switch` renders a focusable control with `role="switch"` and reflects its
  value through `aria-checked`.
- `Field.Label` provides the accessible name via `aria-labelledby`. Use
  `aria-label` or `aria-labelledby` on `Switch.Control` when the switch has no
  visible label.
- `Field.Description` renders helper text and associates it with the switch via
  `aria-describedby`.
- `Field.ErrorMessage` renders error text linked via `aria-describedby` when
  `invalid` is true.
- Disabled switches are removed from the tab order. Read-only switches remain
  focusable and do not change value.
- When `name` is provided, Spar renders a synchronized hidden checkbox input for
  native form submission. `name` is the form field name, not the accessible
  label — supply `aria-label` when the switch has no visible children.

| Key                                 | Behavior                            |
| ----------------------------------- | ----------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggle the focused switch.          |
| <kbd>Tab</kbd>                      | Move focus to the next tabbable UI. |
