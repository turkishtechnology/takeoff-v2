`PhoneInput` is a phone number field with a country picker: the country in the
prefix, the number on the right, as in Takeoff Core. The number is formatted as
the user types by
[libphonenumber-js](https://github.com/catamphetamine/libphonenumber-js)
(`532 123 45 67` in Türkiye, `(201) 555-0123` in the US), and what your code
receives is the E.164 string — `+905321234567`.

## Usage

```tsx
import { Field, PhoneInput } from '@takeoff-ui/react-spar';
```

```tsx
<Field>
  <Field.Label />
  <PhoneInput>
    <PhoneInput.Prefix>
      <PhoneInput.CountrySelect />
      {/* or, for a fixed country: <PhoneInput.DialCode /> */}
    </PhoneInput.Prefix>
    <PhoneInput.Field />
    <PhoneInput.ClearButton />
  </PhoneInput>
  <Field.Description />
  <Field.ErrorMessage />
</Field>
```

The root renders `Input`'s row, so sizes, the focus ring, `Field` inheritance
and the `Prefix` / `Suffix` / `ClearButton` parts are `Input`'s own, re-exposed
so the tree uses one namespace.

## The value is E.164

`onValueChange` receives the E.164 number on every edit that changes it — also
while the number is still partial (`+90532`) — and `''` once the field is empty.
Its second argument is `{ national, formatted, isValid, country }`: the digits
after the dial code, the text the field shows, whether the number is valid for
its country, and that country.

Formatting and validation are libphonenumber-js's, with its `min` metadata;
Spar's mask owns the caret. A trunk prefix is the library's call:
`0532 123 45 67` stays as typed and still reports `+905321234567`, while an
Italian number keeps its leading `0`. Digits past the longest number the country
has are refused. `isValid` only informs you — the field never marks itself
invalid while the user is still typing, so decide when to show the error (on
blur, on submit).

## Countries

Without `countries`, the picker lists every region libphonenumber-js knows,
named in `locale` through `Intl.DisplayNames` (`Türkiye`, `Almanya` in `tr-TR`)
and sorted by that name. Pass `countries` to restrict or order the list; a
consumer list keeps its own order. Each `PhoneCountry` is
`{ code, label?, icon? }` — `icon` is any node, which is how a flag reaches the
trigger and the rows (the package ships no flag set; these demos use emoji).

Picking a country clears the number and moves focus to the field, as Core does:
a number typed for one numbering plan is not a number in another. Typing or
pasting `+<code>…` works too — the country's own code collapses into the
national format, and another listed country's code moves the picker there. A
`+1` number keeps a NANP field on its region (`+1` is shared by 25 of them). A
`value` set from outside that belongs to another listed country moves the picker
and calls `onCountryChange`.

## Forms and `Field`

`name` submits the E.164 number through a hidden input; `CountrySelect` takes
its own `name` for the ISO code. `disabled`, `invalid`, `readOnly` and
`required` are inherited from a surrounding `Field`. The Field's label names the
number field; the picker keeps its own name, and the row's `disabled` /
`readOnly` reach it.

## Customizing the picker

The default trigger shows the icon and the dial code; a search field tops the
list; each row shows icon, name and dial code. The search matches the name, the
ISO code and the dial code, ignoring case and accents — `turkiye`, `tr` and `90`
all find Türkiye, and the four Turkish i's (`I İ ı i`) count as one letter.
Rename it with `searchLabel` / `searchPlaceholder`, change the no-match text
with `emptyLabel`, or drop the field with `searchable={false}` for a short list.
`trigger` and `children` replace the content when the default does not fit.

For a picker that is not a `Select`, `usePhoneInputContext()` gives the active
`country`, the resolved `countries` and `pickCountry`.

## Accessibility

- The trigger shows only an icon and a dial code, so it is named
  `"Country code"` by default. Pass `aria-label` to translate it.
- The list opens on its search field, which is the combobox: arrows move through
  the matches and <kbd>Enter</kbd> picks one. Without the search
  (`searchable={false}`), each row's name is the typeahead key.
- A search that matches nothing is announced through a polite status.
- `PhoneInput.DialCode` is hidden from assistive tech; put the country in the
  `Field.Label` when it matters.
- The number field is `type="tel"` with `autoComplete="tel-national"`, so phones
  open the dial pad and browsers offer saved numbers.

## Bundle size

libphonenumber-js is a dependency of `@takeoff-ui/react-spar`, imported from its
`min` entry: about 33 KB gzipped (142 KB minified), plus 1.5 KB for the example
numbers used as placeholders. Only bundles that import `PhoneInput` include it.
