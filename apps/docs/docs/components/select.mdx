# Select

`Select` is a fully-keyboard, accessible custom select. State (value, open
state, disabled, required) lives on the root; the trigger renders the collapsed
button, and the content portals a positioned dropdown.

## Usage

```tsx
import { Select } from '@takeoff-ui/react-spar';
```

```tsx
<Select>
  <Select.Trigger>
    <Select.Value />
  </Select.Trigger>
  <Select.Content>
    <Select.Group>
      <Select.Label />
      <Select.Item value="...">
        <Select.ItemText />
      </Select.Item>
    </Select.Group>
    <Select.Separator />
  </Select.Content>
</Select>
```

## Accessibility & Keyboard

- `Select.Trigger` renders a button with `role="combobox"`,
  `aria-haspopup="listbox"`, and `aria-expanded`.
- `Select.Content` is a `role="listbox"` portalled to `document.body` by default
  and positioned with Floating UI.
- `Select.Value` is associated with the trigger via `aria-labelledby`.

| Key                                 | Behavior                                                     |
| ----------------------------------- | ------------------------------------------------------------ |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the dropdown or select the highlighted item.            |
| <kbd>↓</kbd> / <kbd>↑</kbd>         | Open the dropdown / move highlight to next or previous item. |
| <kbd>Home</kbd> / <kbd>End</kbd>    | Move highlight to the first / last item.                     |
| <kbd>Esc</kbd>                      | Close the dropdown without changing selection.               |
| typing characters                   | Typeahead — jumps to the first matching item.                |
