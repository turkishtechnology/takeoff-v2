# Card

`Card` groups related content and actions in a flexible surface. It is a
Takeoff-owned wrapper with compound parts for consistent spacing, typography,
and theming.

## Usage

```tsx
import { Card } from '@takeoff-ui/react-spar';
```

```tsx
<Card>
  <Card.Header>
    <Card.Title />
  </Card.Header>
  <Card.Body>
    <Card.Description />
  </Card.Body>
  <Card.Footer />
</Card>
```
