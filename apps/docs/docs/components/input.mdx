# Input

`Input` is a compound, accessible text input. The root owns form state
(`isInvalid`, `disabled`, `required`, `readOnly`), the `Input.Container` is the
bordered row that hosts the field plus optional adornments, and helper / error
text are siblings underneath.

## Usage

```tsx
import { Input } from '@takeoff-ui/react-spar';
```

```tsx
<Input>
  <Input.Label />
  <Input.Container startContent={<Icon />} endContent={<Icon />}>
    <Input.Prefix />
    <Input.Field />
    <Input.Suffix />
  </Input.Container>
  <Input.Description />
  <Input.ErrorMessage />
</Input>
```

## Accessibility

- `Input.Label`, `Input.Description`, and `Input.ErrorMessage` are wired to the
  field via stable IDs derived from the root (`aria-labelledby`,
  `aria-describedby`, `aria-invalid`).
- The asterisk inside `Input.Label` is decorative — `required` is also surfaced
  to assistive tech via the field's native `required` / `aria-required`.
- `Input.Container`'s `startContent` and `endContent` slots render with
  `aria-hidden="true"`; put any meaningful affordance inside `Input.Suffix` /
  `Input.Prefix` (or as a focusable button child) instead.
