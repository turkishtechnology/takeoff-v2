export const popoverDemo = String.raw`
function PopoverDemo() {
  const [time, setTime] = React.useState(new Date(2026, 8, 1, 10, 45));
  const [open, setOpen] = React.useState(false);
  const [draft, setDraft] = React.useState(time);

  const label = pad(time.getHours()) + ':' + pad(time.getMinutes());

  return (
    <Popover
      open={open}
      onOpenChange={(next) => {
        setOpen(next);
        // Reopening always starts from the committed time, so a cancelled
        // edit leaves nothing behind.
        if (next) setDraft(time);

      </Popover.Trigger>

          <TimePicker.Body />
          <TimePicker.Footer>
            <Button
              appearance="text"
              variant="neutral"
              onClick={() => setOpen(false)}
            >
              Cancel
            </Button>
            <Button
              onClick={() => {
                setTime(draft);
                setOpen(false);
              }}
            >
              Apply
            </Button>
          </TimePicker.Footer>
        </TimePicker>
      </Popover.Content>
    </Popover>
  );
}

`TimePicker` picks a time of day inline, as a `Date`. Two bodies pick the same
value: `columns` stacks each unit as a spinning column, `dial` pairs two number
fields with a clock face.

## Usage

```tsx
import { TimePicker } from '@takeoff-ui/react-spar';
```

```tsx
<TimePicker defaultValue={new Date()}>
  <TimePicker.Body />
</TimePicker>
```

`TimePicker.Body` is the picking surface; the root is chrome-free, so a bare
body drops into a `Popover.Content`. Add the opt-in `tk-timepicker-panel` class
for a standalone panel. Inside a `Field` it inherits the label and the
`disabled` / `readOnly` / `invalid` / `required` state.

## Clock

`mode="dial"` swaps the columns for two number fields and a dial. The dial edits
the active field, and picking an hour moves the turn to the minutes. It is
hidden from assistive technology — every value it offers is reachable from the
two fields it drives.

A 24-hour face carries the whole day: 00–11 on the outer ring, 12–23 on the
inner one. A 12-hour face uses the one ring.

## Where AM/PM lives

Under `timeFormat="12"` the meridiem gets a column of its own.
`meridiem="toggle"` takes it out of that row and hands it to a composed
`TimePicker.Meridiem`, a segmented control you place yourself — typically the
header, for a panel too narrow for a fourth column.

```tsx
<TimePicker timeFormat="12" meridiem="toggle">
  <TimePicker.Header>
    <TimePicker.Meridiem />
  </TimePicker.Header>
  <TimePicker.Body />
</TimePicker>
```

The part renders nothing under `meridiem="column"` or a 24-hour clock, so it is
safe to leave composed. It is a `role="radiogroup"`: one tab stop, with the
arrows moving between the two halves.

## Compact

`compact` is the shorter form of whichever body is rendering: the dial stacks
under its number fields instead of sitting beside them, and the column body

## Steps and bounds

`hourStep` / `minuteStep` / `secondStep` thin out what a column offers.
`minTime` / `maxTime` are inclusive and read only the time of day.

A coarse unit stays selectable while **any** finer value it allows is in bounds:
under a 17:30 ceiling the hour 17 works, and picking it pulls the minutes down
to 30.

## Type

`divided` rules the header and footer off the picking surface; `light` tints the
surface and flips the selection band to white against it; `dark` and `primary`
repaint it outright.

It does not reach content composed into the panel — a `Button` carries its own
colours, so `dark` and `primary` need `variant="white"`. For a treatment the
package does not ship, override the `--tk-timepicker-*` palette on the root.

## Keyboard

Each unit — a `columns` column or a `dial` field — is one tab stop.

| Key                         | Action                                       |
| --------------------------- | -------------------------------------------- |
| <kbd>↑</kbd>                | Select the value drawn above the current one |
| <kbd>↓</kbd>                | Select the value drawn below the current one |
| <kbd>Page Up</kbd>          | Move five values up                          |
| <kbd>Page Down</kbd>        | Move five values down                        |
| <kbd>Home</kbd>             | Jump to the first value the bounds allow     |
| <kbd>End</kbd>              | Jump to the last value the bounds allow      |
| <kbd>0</kbd>–<kbd>9</kbd>   | Type the value                               |
| <kbd>A</kbd> / <kbd>P</kbd> | Set the half-day                             |

Columns read top-to-bottom as ascending, so <kbd>↑</kbd> selects what is drawn
above — the smaller value. Values the bounds forbid are stepped over rather than
landed on.

A typed digit lands straight away and waits a second for a second one, so `4`
selects 4 and `45` selects 45. A pair that names no value starts over from its
last digit.
