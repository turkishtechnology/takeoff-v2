# Tooltip

`Tooltip` displays a floating label on hover or focus to provide brief
contextual information. It wraps the Spar headless Tooltip primitive and adds
Takeoff visual vocabulary — variant, header, description, and arrow slots.

## Usage

```tsx
import { Tooltip } from '@takeoff-ui/react-spar';
```

```tsx
<Tooltip>
  <Tooltip.Trigger>Hover me</Tooltip.Trigger>
  <Tooltip.Content>
    <Tooltip.Description>Helpful info</Tooltip.Description>
  </Tooltip.Content>
</Tooltip>
```

## Accessibility & Keyboard

- Trigger uses `aria-describedby` pointing to the content element.
- Content has `role="tooltip"`.
- Tooltip respects `WCAG 1.4.13` — hoverable content remains visible while the
  pointer is over it.
- Escape key dismisses the tooltip and returns focus to the trigger.

| Key               | Behavior                                    |
| ----------------- | ------------------------------------------- |
| <kbd>Escape</kbd> | Dismiss the tooltip.                        |
| <kbd>Tab</kbd>    | Focus trigger shows tooltip; blur hides it. |

## Anatomy

```tsx
<Tooltip>
  {' '}
  {/* Root — state management */}
  <Tooltip.Trigger> {/* Hover/focus target */}…</Tooltip.Trigger>
  <Tooltip.Content>

    {/* Floating popup */}
    <Tooltip.Header>…</Tooltip.Header> {/* Optional bold heading */}
    <Tooltip.Description>…</Tooltip.Description> {/* Body text */}
    <Tooltip.Arrow /> {/* Optional arrow */}
  </Tooltip.Content>
</Tooltip>
```
