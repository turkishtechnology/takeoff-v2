# Checkbox

`Checkbox` lets users select one or more options or toggle a single setting on
or off, with first-class support for an indeterminate "mixed" state. Takeoff
visual props stay on the wrapper while Spar owns checked state, forms, focus,
and keyboard behavior.

## Usage

```tsx
import { Checkbox } from '@takeoff-ui/react-spar';
```

```tsx
<Checkbox>
  <Checkbox.Indicator>
    <Checkbox.Icon />
  </Checkbox.Indicator>
  <Checkbox.Label />
  <Checkbox.Description />
</Checkbox>
```

## Indeterminate

`indeterminate` overrides `checked` and `defaultChecked` while set, and emits
`aria-checked="mixed"`. The first user toggle transitions out of the mixed state
— `onChange` is always called with a plain `boolean`. In uncontrolled mode, set
`indeterminate` only on the initial render and clear it from your own state
after the first change.

## Accessibility & Keyboard

- `Checkbox` renders a focusable control with `role="checkbox"` and reflects its
  value through `aria-checked` (including `"mixed"` for the indeterminate
  state).
- `Checkbox.Label` provides the accessible name. Use `aria-label` or
  `aria-labelledby` on the root when the checkbox has no visible label.
- `Checkbox.Description` is descriptive supplementary text. Wire it to the
  control with `aria-describedby` on the root when you need the description
  announced.
- Setting `required` on the root renders a visual asterisk inside
  `Checkbox.Label` and exposes `aria-required`.
- Disabled checkboxes are removed from the tab order. Read-only checkboxes
  remain focusable and do not change value.

| Key              | Behavior                            |
| ---------------- | ----------------------------------- |
| <kbd>Space</kbd> | Toggle the focused checkbox.        |
| <kbd>Tab</kbd>   | Move focus to the next tabbable UI. |
