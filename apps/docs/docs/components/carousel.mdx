# Carousel

`Carousel` shows a set of slides one step at a time, with arrows, page
indicators and optional autoplay. Behavior (the index, the page model, keyboard,
autoplay and ARIA) comes from Spar's headless `Carousel`; this wrapper adds the
Takeoff track, controls and layout.

## Usage

```tsx
import { Carousel } from '@takeoff-ui/react-spar';
```

```tsx
<Carousel aria-label="Featured destinations">
  <Carousel.Viewport>
    <Carousel.Slide />
  </Carousel.Viewport>
  <Carousel.Controls>
    <Carousel.PrevTrigger />
    <Carousel.Indicators>
      <Carousel.AutoplayTrigger />
    </Carousel.Indicators>
    <Carousel.NextTrigger />
  </Carousel.Controls>
</Carousel>
```

`Carousel.Controls` without children renders exactly the set above. Name every
carousel with `aria-label` or `aria-labelledby`: the root is a `region`
landmark.

## Slides per view

`slidesPerView` shows several slides at once. Navigation still moves one slide
per step, so there is one indicator per start position
(`slides - slidesPerView + 1`). Without `loop`, the arrow at an end is hidden.

## Autoplay

`autoplay` advances every `autoplayInterval` milliseconds (3000 by default). The
play/pause control appears in front of the indicators. Rotation pauses while the
pointer is over the carousel or focus is inside it, stops for good when the user
presses pause, and does not start when the user prefers reduced motion. Without
`loop`, it stops on the last page.

## Controls placement and position

`controlsPlacement` puts the controls over the slides (`inside`) or in reserved
room around them (`outside`). `controlsPosition` lays them out: `distributed`
(arrows on the sides, indicators along the bottom), or one bar at the `start` or
`end` edge.

## Vertical

With `orientation="vertical"` slides move up and down and ArrowUp / ArrowDown
navigate. Give the root a height (it defaults to 300px). `start` / `end` are the
inline-start / inline-end edges here, and `distributed` puts the arrows at the
top and bottom with the indicators on the inline-end side.

## Accessibility

The root is a `region` with `aria-roledescription="carousel"`; each slide is a
`group` with `aria-roledescription="slide"` and a "2 of 5" name. Slides outside
the visible window are `inert`, so their links and buttons are not tab stops.
The viewport is a polite live region except while rotating. The arrows,
indicators and play/pause control are buttons that point at the viewport with
`aria-controls`; the current indicator has `aria-current="true"`.

| Key                        | Action                                             |
| -------------------------- | -------------------------------------------------- |
| `ArrowRight` / `ArrowDown` | Next slide (horizontal / vertical).                |
| `ArrowLeft` / `ArrowUp`    | Previous slide (horizontal / vertical).            |
| `Tab`                      | Moves through the controls and the visible slides. |

The horizontal arrows flip in right-to-left layouts. Arrow keys typed in a text
field inside a slide stay with the field.
