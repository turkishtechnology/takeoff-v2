`CurrencyInput` is an amount field with a currency: the amount on the left, the
currency picker in the suffix, as in Takeoff Core. The amount is grouped as the
user types by Spar's `number` mask (`1.234.567,89` in `tr-TR`, `1,234,567.89` in
`en-US`), and what your code receives is a plain `number`.

## Usage

```tsx
import { CurrencyInput, Field } from '@takeoff-ui/react-spar';
```

```tsx
<Field>
  <Field.Label />
  <CurrencyInput>
    <CurrencyInput.Prefix />
    <CurrencyInput.Field />
    <CurrencyInput.ClearButton />
    <CurrencyInput.Suffix>
      <CurrencyInput.CurrencySelect />
      {/* or, for a fixed currency: <CurrencyInput.Symbol /> */}
    </CurrencyInput.Suffix>
  </CurrencyInput>
  <Field.Description />
  <Field.ErrorMessage />
</Field>
```

The root renders `Input`'s row, so sizes, the focus ring, `Field` inheritance
and the `Prefix` / `Suffix` / `ClearButton` parts are `Input`'s own, re-exposed
so the tree uses one namespace.

## The value is a number

`onValueChange` receives a `number` on every edit that changes the amount, and
`undefined` once nothing names one — an empty field or a lone `-`. So "no amount
yet" stays distinct from a real `0`. While the user types `1.234,` the field
keeps the trailing comma and reports `1234`.

Formatting is the mask's job, not this component's: grouping, the decimal mark
and the caret come from Spar, driven by `locale`. Nothing is padded on blur — a
typed `1.234,5` stays `1.234,5`.

## Locale and digits

`locale` decides the separators and the symbol. It defaults to the runtime's;
pass it explicitly on server-rendered pages, where the server's locale can
differ from the browser's.

The field accepts as many fraction digits as the currency has (TRY 2, JPY 0, KWD
3). Picking a currency with fewer digits cuts the amount to match.
`decimalScale` overrides the count, `integerScale` caps the integer digits, and
`allowNegative` lets a minus sign in.

## Customizing the picker

Each `CurrencyOption` is `{ code, label?, symbol?, icon? }`. The default trigger
shows the icon and the code; a search field tops the list; each row shows icon,
symbol and name.

The search matches the code, the name and the symbol, ignoring case and accents
— `try`, `turk` and `₺` all find the lira, and the four Turkish i's (`I İ ı i`)
count as one letter. Rename it with `searchLabel` / `searchPlaceholder`, change
the no-match text with `emptyLabel`, or drop the field with `searchable={false}`
for a short list. `icon` is any node — the package ships no flag set. `trigger`
and `children` replace the content when the default does not fit.

active `currency` and `setCurrency`.

## Accessibility

- The trigger shows only an icon and a code, so it is named `"Currency"` by
  default. Pass `aria-label` to translate it.
- The list opens on its search field, which is the combobox: arrows move through
  the matches and <kbd>Enter</kbd> picks one. Without the search
  (`searchable={false}`), each row's `label` is the typeahead key.
- A search that matches nothing is announced through a polite status.
- `CurrencyInput.Symbol` is hidden from assistive tech; name the field with a
  `Field.Label`.
- The amount field opens a numeric keyboard (`inputMode="decimal"`, or
  `"numeric"` when the currency has no fraction) and turns autocomplete off.
