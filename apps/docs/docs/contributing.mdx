# Contributing

`@takeoff-ui/react-spar` lives in the
[`turkishtechnology/takeoff-spar`](https://github.com/turkishtechnology/takeoff-spar)
monorepo. Contributions follow a short, strict path designed to keep every
component at the same level of polish.

## The readiness gate

Before a new component can merge, it has to follow the
[`component authoring contract`](https://github.com/turkishtechnology/takeoff-spar/blob/main/docs/component-authoring-contract.md):

- Wrapper + types + base metadata.
- Full public-surface unit tests.
- Smoke test in `e2e/smoke-verifier.spec.ts`.

## Starting a port

1. Open an issue titled `port: <ComponentName>`.
2. Fill in the API decision framework checklist — leaf or compound, prop parity
   with Core, slot taxonomy, data-attribute emission.
3. Get sign-off on the framework answers before writing code.
4. Scaffold the component, tests, and docs in one PR.

## Review workflow

- One code owner + one docs owner review.
- Breaking changes (surface contract violations) require explicit maintainer
  approval before merge.

## Style & formatting

- ESLint + Prettier run on pre-commit via Husky.
- `pnpm lint` and `pnpm check-types` are required to pass CI.
- No mocking a database in tests (we hit the real one — lesson learned the hard
  way).

## Local development

```bash
pnpm install
pnpm --filter docs dev          # runs the docs site
pnpm --filter @takeoff-ui/react-spar test  # component unit tests
```
