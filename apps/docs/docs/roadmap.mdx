[`component authoring contract`](https://github.com/turkishtechnology/takeoff-spar/blob/main/docs/component-authoring-contract.md).

## What "priority order" means

We ship **Popover before Tooltip/DropdownMenu/Select** because those three
components all depend on Popover's positioning engine. We ship **Radio and
Toggle before Popover** because they don't block anything and give form users
immediate value.

Priority can shift when the Takeoff UI Core source of truth ships new primitives
or a consumer team signals a blocker.

## How decisions happen

Every new component starts with a source-backed contract before a line of code
is written. The contract answers: leaf or compound, which parts are real, which
props align with Core, which `data-*` hooks are emitted, and which behavior
belongs upstream in Spar.
