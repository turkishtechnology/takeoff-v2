# Blocks

Blocks are larger pieces of UI, such as a chatbot, composed from
`@takeoff-ui/react-spar` components. They are not package exports: each block is
a single file you copy into your app and own. Wire it to your own data and
change the markup as your product needs.

Because a block lives in your code, updates to a block page do not reach your
app automatically. Compare against the page when you want to pick up a change.

## AI

| Block                              | Use it for                                                                |
| ---------------------------------- | ------------------------------------------------------------------------- |
| [Chatbot](/docs/blocks/ai/chatbot) | A chat assistant panel, floating behind a launcher or embedded in a page. |
