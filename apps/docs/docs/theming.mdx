# Theming

`@takeoff-ui/react-spar` keeps component examples intentionally isolated. Load
styles once, mount `SparReactProvider` once, and let component pages focus on
the component API.

## App Shell Setup

```tsx
import '@takeoff-design/tokens/css/default/theme.css';
import { SparReactProvider } from '@takeoff-ui/react-spar';

export function AppShell() {
  return (
    <SparReactProvider colorMode="light">
      <App />
    </SparReactProvider>
  );
}
```

- Install `@takeoff-design/tokens` alongside `@takeoff-ui/react-spar`.
- Import `@takeoff-design/tokens/css/default/theme.css` once in the application
  entry or shell.
- Mount `SparReactProvider` once near the shell. It writes `data-theme` from
  `colorMode` and `lang` from `locale` onto a `display: contents` wrapper.
- Change `colorMode` at that same boundary when a route, story, or preview needs
  a different presentation.
- `@takeoff-ui/react-spar` does not bundle component CSS; the shared Takeoff
  token package remains the style distribution layer.
- Component demos in this site omit that boilerplate on purpose; the preview
  surface already runs inside a themed shell.

## Provider Surface

`SparReactProvider` currently exposes three props:

| Prop         | Type                                  | Notes                                                                                                                                                                                                                             |
| ------------ | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `colorMode`  | `'light' \| 'dark'` (default `light`) | Written to `data-theme` on the provider element.                                                                                                                                                                                  |
| `locale`     | `string` (optional)                   | Written to `lang` on the provider element.                                                                                                                                                                                        |
| `components` | `ComponentsThemeMap` (optional)       | Per-component `defaultProps`, `classNames`, and `slotProps`. See the package [README](https://github.com/ulasturann/takeoff-spar/blob/main/packages/react-spar/README.md#component-customization) for the customization contract. |

RTL, density, and direction-aware tokens are not part of the current provider
contract. Set `html[dir]` at the framework level (Docusaurus, Next.js) when you
need RTL layout.
