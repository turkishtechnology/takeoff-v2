# Theming

`@takeoff-ui/react-spar` keeps component examples intentionally isolated. Load
styles once, mount `ThemeProvider` once, and let component pages focus on the
component API.

## App Shell Setup

```tsx
import '@takeoff-ui/react-spar/styles';
import { ThemeProvider } from '@takeoff-ui/react-spar';

export function AppShell() {
  return (
    <ThemeProvider colorMode="light" density="comfortable">
      <App />
    </ThemeProvider>
  );
}
```

- Import `@takeoff-ui/react-spar/styles` once in the application entry or shell.
- Mount `ThemeProvider` once near the shell. It writes `data-theme`,
  `data-color-mode`, and `data-density` for the shipped CSS contract.
- Change `colorMode` or `density` at that same boundary when a route, story, or
  preview needs a different presentation.
- Component demos in this site omit that boilerplate on purpose; the preview
  surface already runs inside a themed shell.
