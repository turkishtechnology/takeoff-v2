## Playground

The React wrapper keeps Takeoff's visual contract while delegating toggle state,
ARIA wiring, and keyboard navigation to the underlying Spar Accordion primitive.
The visible header surface is rendered through a div-backed trigger so grouped
and divided header styling stays aligned with the original Takeoff UI markup.

Keyboard navigation follows the
[WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/)
pattern: `Up` / `Down` move focus between headers, `Home` and `End` jump to the
first and last header, and `Enter` / `Space` toggle the focused panel.

  const [activeIndex, setActiveIndex] = React.useState(0);

return ( <div style={{ width: '100%', maxWidth: 640, margin: '0 auto' }}>
<Accordion activeIndex={activeIndex} onActiveIndexChange={(index) =>
setActiveIndex(index)} > <AccordionItem header="Flight details"> View your

</Accordion> </div> ); }`} previewMinHeight={220}

## Template

Accordion is template-friendly at the content layer and reasonably flexible at
the header layer because `header` is `ReactNode` and panel bodies accept
arbitrary children. The trigger shell, arrow placement, and item anatomy remain
product-owned.

## Type

Use `type` to switch between visual styles. `grouped` wraps each item in a
bordered card while `divided` separates header and content with independent
borders.
