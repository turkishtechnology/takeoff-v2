## Playground

The React wrapper keeps Takeoff's visual contract while delegating toggle state,
ARIA wiring, and keyboard navigation to the underlying Spar Accordion primitive.
The visible header surface is rendered through a div-backed trigger so grouped
and divided header styling stays aligned with the original Takeoff UI markup.

Accordion is a compound component. Compose each panel from `Accordion.Item`,
`Accordion.Header`, `Accordion.Title`, and `Accordion.Content`. `Accordion.Icon`
and `Accordion.Arrow` are optional header parts.

Keyboard navigation follows the
[WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/)
pattern: `Up` / `Down` move focus between headers, `Home` and `End` jump to the
first and last header, and `Enter` / `Space` toggle the focused panel.

## Template

Accordion is template-friendly at the content layer and reasonably flexible at
the header layer — `Accordion.Title` accepts any `ReactNode`, `Accordion.Icon`
renders a leading glyph (string values render as Material Symbols), and
`Accordion.Content` accepts arbitrary children. The trigger shell and item
anatomy remain product-owned.

## Type

Use `type` to switch between visual styles. `grouped` wraps each item in a
bordered card while `divided` separates header and content with independent
borders.

`mode` controls density. `compact` removes margins and rounds so items stack

The `size` prop on `Accordion.Item` adjusts header typography, padding, and
spacing.

<Size />

## Arrow Position

`Accordion.Arrow` placement inside `Accordion.Header` determines which side the
expand/collapse chevron appears on. Render it after `Accordion.Title` for the
default right-aligned chevron, or before `Accordion.Title` to place it on the
left. Omit `Accordion.Arrow` entirely to hide the chevron.

<ArrowPosition />

## Custom Expand / Collapse Icons

Override the default chevrons with the `expandIcon` and `collapseIcon` props on
`Accordion.Arrow`, or pass a render-prop child that receives the resolved
`isOpen` state for fully custom arrow content.
