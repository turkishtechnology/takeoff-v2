## Playground

The React wrapper preserves the Takeoff Button product surface — `variant`,
`type`, `size`, `loading`, `disabled`, `fullWidth`, and `mode` — while Spar owns
the underlying interaction model, focus handling, and ARIA wiring. Content is
always composed from the compound subcomponents: `Button.Label`,
`Button.LeadingIcon`, `Button.TrailingIcon`, and `Button.Spinner`.

## Template

Button is template-friendly for inline composition. Compose `Button.Label`,
`Button.LeadingIcon`, and `Button.TrailingIcon` under the root, and use
`slotProps` plus `fullWidth` to shape a richer CTA without rebuilding the
component from scratch.

<Template />

## Variant

Use `variant` when the action meaning changes. The component keeps the same
layout contract while the tone moves from primary to neutral, warning, or
danger.

<Variant />

## Type

Use `type` to control visual weight after the semantic tone is chosen. This
keeps prominence separate from intent.

<TypeExample />

## Size and Layout

`size` adjusts density. `fullWidth` gives an action its own line when the next
step should read clearly and without competition.

<SizeAndWidth />

## States

Reach for `loading` and `disabled` for operational feedback. Render
`Button.Spinner` alongside `Button.Label` when loading — the spinner slot
auto-hides when `loading` is `false`. For toggle behavior, keep native
`aria-pressed`; Spar already exposes the pressed state for styling.

<States />

## Form Semantics

Use `mode='submit'` or `mode='reset'` when the button belongs to a form. The
wrapper preserves native behavior instead of recreating it in JavaScript.
