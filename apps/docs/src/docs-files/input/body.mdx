## Playground

The React wrapper exposes Input as a compound component. State props such as
`type`, `size`, `disabled`, `readOnly`, `required`, `invalid`, `clearable`,
`loading`, `value`, `defaultValue`, and `onChange` live on the `<Input>` root.
Every visual slot — label, asterisk, container, field, leading/trailing icons,
prefix/suffix, clear button, spinner, description, and error message — is a
dedicated subcomponent. ARIA relationships between label, description, error,
and the native input are owned by the Spar Input primitive — the wrapper never
recreates them.

The Stencil modes `password`, `counter`, `chips`, and Cleave.js-based `mask` are
intentionally out of scope for this wrapper. Those will ship as separate
wrappers (`PasswordInput`, `NumberInput`, `ChipsInput`) when their upstream
primitives are available.

## Template

Input is built for form-field composition. The canonical subcomponents —
`Input.Label`, `Input.Asterisk`, `Input.Container`, `Input.Field`,
`Input.LeadingIcon`, `Input.TrailingIcon`, `Input.Prefix`, `Input.Suffix`,
`Input.ClearButton`, `Input.Spinner`, `Input.Description`, and
`Input.ErrorMessage` — map 1:1 to the `data-slot` anatomy, keeping product
styling hooks stable across variants.

`Input.ClearButton` keeps the `<button>` structural owner and only renders when
`clearable` is set on the root and the field has a value. Pass custom children
to replace the default icon content. `Input.Suffix` renders inline nodes such as
keyboard hints and composes with the clear button without breaking the trailing
slot order.

## Basic Usage

Compose `Input.Label` with `Input.Asterisk` and add `Input.Description` below
the container for the common product field. Setting `required` on the root makes
`Input.Asterisk` render; it stays hidden otherwise.

## Validation

`invalid` on the root flips the field into the error state. `Input.ErrorMessage`
renders with `role="alert"` while `invalid` is `true`, and `Input.Description`
is suppressed at the same time so screen readers do not read both.

<Validation />

## Adornments

Use `Input.LeadingIcon` or `Input.TrailingIcon` for inline icon slots. Both
accept a React node or a Material Symbols ligature string. `Input.Prefix` and
`Input.Suffix` render inline text or nodes before and after `Input.Field`. Place
`Input.Spinner` inside the container to show a loading indicator when `loading`
is set; it yields automatically when `Input.ClearButton` is active.

## States

`disabled` and `readOnly` on the root carry the native HTML semantics. `size`
selects the dimension track from the shared token recipe and is exposed on the
root and container as `data-size` for product styling.
