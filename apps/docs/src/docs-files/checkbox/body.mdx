## Playground

Checkbox preserves the `tk-checkbox` contract — `label`, `description`, `type`,
`size`, `disabled`, `readOnly`, `required`, `invalid`, `name`, `value`,
`indeterminate`, `onChange` — on top of the
[`@turkish-technology/spar`](https://spar.app.turkishtechlab.com/docs/Components/Checkbox)
primitive. The spar primitive owns keyboard handling, focus, and ARIA wiring;
the wrapper adds the Takeoff visual slot anatomy and the tri-state payload
(`boolean | null`) that matches `tk-change`.

## Template

The canonical slots — `root`, `indicator`, `icon`, `text`, `label`,
`description` — stay stable across variants. State flows through the root as
`data-checked`, `data-indeterminate`, `data-disabled`, `data-readonly`,
`data-invalid`, `data-focus`, and `data-hover`, so the token recipe does all the
visual state work without touching JS.

The `type="card"` variant wraps the same slots in a bordered container that
reacts to hover and focus; the `size` scale picks the indicator box footprint
(`base` or `small`).

## Basic Usage

Use `label` and `description` together for the common form-row layout. The
wrapper is uncontrolled by default (`defaultValue` seeds the initial state) and
can be promoted to controlled via `value` + `onChange`.

<Basic />

## Indeterminate (tri-state)

`value: null` flips the box into the indeterminate state, mirroring the
`tk-checkbox` `indeterminate` prop. The `onChange` payload is `boolean | null`,
matching the `tk-change` event contract. Spec behavior — an indeterminate box
advances to `true` on next toggle — comes from the spar primitive.

<Indeterminate />

## Validation

Pair `invalid` with `required` to light up the danger recipe without altering
the ARIA tree. The wrapper only stamps `data-invalid` on the root; the token
recipe drives the border, icon fill, and hover treatment.

<Validation />

## States

`disabled` and `readOnly` follow their native semantics — both lock interaction
while preserving focus semantics (`readOnly` remains focusable). `size` selects
the indicator footprint from the token recipe (`base` or `small`). `type="card"`
wraps the row in a bordered container for selection lists.
