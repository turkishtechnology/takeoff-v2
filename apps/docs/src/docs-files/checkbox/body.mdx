## Playground

Checkbox preserves the `tk-checkbox` contract — `type`, `size`, `disabled`,
`readOnly`, `required`, `invalid`, `name`, `value`, `indeterminate`, `onChange`
— on top of the
[`@turkish-technology/spar`](https://spar.app.turkishtechlab.com/docs/Components/Checkbox)
primitive. The spar primitive owns keyboard handling, focus, and ARIA wiring;
the wrapper adds the Takeoff visual slot anatomy as a compound composition —
`Checkbox.Indicator`, `Checkbox.Icon`, `Checkbox.Content`, `Checkbox.Label`,
`Checkbox.Description` — and the tri-state payload (`boolean | null`) that
matches `tk-change`.

## Template

The canonical slots — `root`, `indicator`, `icon`, `content`, `label`,
`description` — stay stable across variants and map 1:1 to the compound
subcomponents. State flows through the root as `data-checked`,
`data-indeterminate`, `data-disabled`, `data-readonly`, `data-invalid`,
`data-focus`, and `data-hover`, so the token recipe does all the visual state
work without touching JS.

The `type="card"` variant wraps the same slots in a bordered container that
reacts to hover and focus; the `size` scale picks the indicator box footprint
(`base` or `small`).

## Basic Usage

Compose `Checkbox.Label` and `Checkbox.Description` inside `Checkbox.Content`
for the common form-row layout. The wrapper is uncontrolled by default
(`defaultValue` seeds the initial state) and can be promoted to controlled via
`value` + `onChange`. `Checkbox.Indicator` hosts the box; an empty
`Checkbox.Indicator` auto-renders `Checkbox.Icon`, which in turn renders the
default check / remove glyph based on state.

## Indeterminate (tri-state)

`value: null` flips the box into the indeterminate state, mirroring the
`tk-checkbox` `indeterminate` prop. The `onChange` payload is `boolean | null`,
matching the `tk-change` event contract. Spec behavior — an indeterminate box
advances to `true` on next toggle — comes from the spar primitive.

<Indeterminate />

## Validation

Pair `invalid` with `required` to light up the danger recipe without altering
the ARIA tree. The wrapper only stamps `data-invalid` on the root; the token
recipe drives the border, icon fill, and hover treatment. Swap
`Checkbox.Description` content conditionally to surface error copy alongside the
helper text.

<Validation />

## States

`disabled` and `readOnly` follow their native semantics — both lock interaction
while preserving focus semantics (`readOnly` remains focusable). `size` selects
the indicator footprint from the token recipe (`base` or `small`). `type="card"`
wraps the row in a bordered container for selection lists.
