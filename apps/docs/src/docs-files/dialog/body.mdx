## Playground

Dialog is a compound component. The root owns modal state (`visible`,
`headerType`, `variant`, `maskVariant`, `preventDismiss`) while every visible
region is composed from named parts: `Dialog.Mask`, `Dialog.Panel`,
`Dialog.Header`, `Dialog.SignIcon`, `Dialog.TitleGroup`, `Dialog.Title`,
`Dialog.Description`, `Dialog.CloseButton`, `Dialog.Body`, `Dialog.Footer`, and
`Dialog.FooterActions`. Focus trapping, ARIA wiring, and Escape handling stay on
the underlying Spar Dialog primitive.

Dismissal is owned by Spar: pressing `Esc`, clicking the mask, or activating
`Dialog.CloseButton` calls `onVisibleChange(false)`. Set `preventDismiss` to
lock the dialog open until a product action resolves it.

## Anatomy

Compose the full dialog by nesting the compound parts inside the root. The
canonical shape is:

```tsx
<Dialog visible={...} onVisibleChange={...} variant="info" headerType="basic">
  <Dialog.Mask />
  <Dialog.Panel>
    <Dialog.Header>
      <Dialog.SignIcon />
      <Dialog.TitleGroup>
        <Dialog.Description>Review the fare difference</Dialog.Description>
        <Dialog.Title>Confirm upgrade</Dialog.Title>
      </Dialog.TitleGroup>
      <Dialog.CloseButton />
    </Dialog.Header>
    <Dialog.Body>Review details below.</Dialog.Body>
    <Dialog.Footer>
      <Dialog.FooterActions>
        <Button><Button.Label>Cancel</Button.Label></Button>
        <Button><Button.Label>Confirm</Button.Label></Button>
      </Dialog.FooterActions>
    </Dialog.Footer>
  </Dialog.Panel>
</Dialog>
```

Every part is optional. Omit `Dialog.Header`, `Dialog.Footer`, or
`Dialog.SignIcon` when a surface doesn't need them. `Dialog.SignIcon` accepts
children to override the variant-driven default icon, and `Dialog.CloseButton`
accepts children to replace its icon.

## Template

Dialog is the strongest templating surface in the current set. Because each
region is a named compound part, you can replace the header, body, and footer
with bespoke layouts while `Dialog.Title`, `Dialog.Description`, and
`Dialog.CloseButton` keep accessibility wiring and dismiss behavior on the
underlying Spar primitive.

## Header Types

`headerType` preserves the original Takeoff header treatments without changing
the dialog body contract. The value is forwarded to `Dialog.Header` as a
`data-header-type` attribute and class hook.

<HeaderTypes />

## Variants

`variant` changes the sign icon treatment and tone of the dialog. Pair it with
`Dialog.SignIcon` to render the variant-appropriate icon.

## Mask Treatments

Use `maskVariant`, `isMaskBlur`, and `hideBackdrop` to tune the surrounding
overlay without moving away from the modal behavior contract. `Dialog.Mask`
