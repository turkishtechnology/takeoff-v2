## Playground

The React wrapper keeps the Takeoff Dialog product surface centered on
`visible`, `headerType`, `variant`, `maskVariant`, and `preventDismiss`. The old
slot API becomes ReactNode props such as `headerSlot`, `contentSlot`,
`footerSlot`, and `footerActions`, while focus trapping and ARIA wiring stay on
the underlying Spar Dialog primitive.

Dismissal is owned by Spar: pressing `Esc` or clicking the mask calls
`onVisibleChange(false)`. Set `preventDismiss` to lock the dialog open until a
product action resolves it.

<LiveCode
  code={`() => {
  const [visible, setVisible] = React.useState(false);

return ( <div style={{ display: 'flex', justifyContent: 'center' }}> <Button
onClick={() => setVisible(true)}>Open dialog</Button>

      <Dialog
        visible={visible}
        onVisibleChange={setVisible}
        header="Upgrade cabin"
        subheader="Review the fare difference before you continue."
        containerStyle={{ width: '460px' }}
        footerActions={
          <>
            <Button type="text" variant="neutral" onClick={() => setVisible(false)}>
              Cancel
            </Button>
            <Button>Continue</Button>
          </>
        }
      >
        You can keep Takeoff's dialog product props such as visible, headerType,
        variant, maskVariant, and preventDismiss while Spar owns focus trapping,
        overlay semantics, and Escape handling.
      </Dialog>

## Template

`contentSlot`, `footerSlot`, `footerActions`, and `containerSlot` let you
replace most visible regions while Spar continues to own modal behavior.
