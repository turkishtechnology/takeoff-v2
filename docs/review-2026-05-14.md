# takeoff-v2 review — 2026-05-14

> **Durum (2026-05-14):** §1.1 (composeRootAttrs API), §1.2 (state-only root),
> §2.1 (DrawerHeader/Body/Footer polymorphism), §2.3 (TooltipTrigger render-prop

Mimari, komponent ve Spar sarmallaması üzerine yapılan derin inceleme. Aşağıdaki

çıkarılmıştır.

## 1. Mimari problemler

### 1.1 `composeRootAttrs.stateAttrs` tema defaultlarını bypass ediyor

`packages/react-spar/src/core/composeRootAttrs.ts:62-87` önce props'u tema ile
merge ediyor, ama `stateAttrs` parametresi çağrıdan önce hesaplanmış literal
alıyor. Sonuç: yazarın elinde sadece pre-merge `props` değerleri var.

- `docs/component-authoring-contract.md:374-377` örneği `props.variant`'ı
  stateAttrs'a koyuyor — `theme.defaultProps.variant` uygulanmıyor ama
  `data-variant` yanlış değeri yazıyor.
- `Accordion.tsx:45-52` ve `Drawer.tsx:18-23` bunu manuel olarak
  rest-destructure sonrası `rootAttrs`'a ek spread ile çözmüş (doğru ama
  dokümante şekil değil).
- `Button.tsx:34-44` ve `TooltipContent.tsx:14-20` ise tema bypassı şeklinde
  bug: `variant`, `size`, `appearance` props'tan destructure ediliyor,
  `theme.defaultProps` hiç uygulanmıyor.

Etki: provider'da
`components: { Button: { defaultProps: { variant: 'secondary' } } }` veren
consumer `data-variant="primary"` görüyor — silent failure.

Önerilen fix: API'yi `stateAttrs: (merged) => ({...})` callback'e çevir, tüm
wrapper'ları tek desene indir.

### 1.2 State-only root'lar `className`/`classNames`/`slotProps` yutuyor

`spar/packages/spar/src/components/Dialog/Dialog.tsx:110` sadece
`<DialogContext.Provider>` döndürüyor — DOM yok. Aynısı Tooltip root için de
geçerli.

- `packages/react-spar/src/components/drawer/types.ts:44-49` `className`,
  `classNames`, `slotProps`'i public API'da tutuyor.
- `packages/react-spar/src/components/drawer/Drawer.tsx:14-27` bunları
  `<SparDialog>`'a spread ediyor → sessizce siliniyor.

Contract (`docs/component-authoring-contract.md:313-314`): _"State-only roots…
accept no `as` and no native HTML props"_ — tip ve doc çelişiyor. Bkz. bölüm
"State-only root tartışması" altında.

### 1.3 Button compound-only baseline ile çelişiyor

`packages/react-spar/docs/coding-standards.md:75-76`:

> _Every component does ship compound subcomponents. Even leaf controls (Button,
> Checkbox) expose at minimum a Label and adornment subcomponents._

`packages/react-spar/docs/coding-standards.md:329`:

> _Button… every .Label / .Icon / .Indicator / .Spinner part is
> react-enhancement._

Gerçek `Button.tsx`: `startIcon`/`endIcon`/`children` saf prop-driven, hiç
compound yok. `Button.Label` ve `Button.Spinner` yok. Çelişki net.

## 2. Komponent-bazlı hatalar

### 2.1 Polymorphic tip, polymorphic olmayan implementation

`DrawerHeader.tsx:23`, `DrawerBody.tsx:17`, `DrawerFooter.tsx:23` tipler
`PolymorphicProps<'div', T, ...>` ama JSX hardcoded `<div>`. Consumer
`<Drawer.Header as="header">` derse tip onaylıyor; runtime `<div as="header">`
üretiyor (geçersiz HTML).

Düzeltme: `const Component = as ?? 'div'` ve `<Component>` render.

### 2.2 DrawerPanel Spar davranışını yeniden implement ediyor + consumer

callback'lerini yutuyor

`DrawerPanel.tsx:26-31`:

```ts
const dismissHandlers = !dismissable && {
  onEscapeKeyDown: preventDefault,
  onPointerDownOutside: preventDefault,
};
<SparDialogContent {...panelProps} ... {...dismissHandlers}>
```

`dismissHandlers` `panelProps`'tan sonra spread olduğu için `!dismissable`
durumunda consumer'ın geçtiği `onEscapeKeyDown`/`onPointerDownOutside`
callback'leri sessizce siliniyor. Contract'in "Fix Spar first" kuralı ihlali —
`dismissable` Spar'a `DialogContent` üzerinde gerçek prop olarak çıkarılmalı.

### 2.3 Tooltip render-prop children eksik

`spar/packages/spar/src/components/Tooltip/TooltipTrigger.tsx:171-174`
function-as-children destekliyor. Wrapper `tooltip/types.ts:27-34`
`Pick<SparTooltipTriggerProps, 'children'>` koymadığı için consumer render-prop
kullanamıyor. Contract `docs/component-authoring-contract.md:317-322` bunu
açıkça gerektiriyor.

### 2.4 `as never` ile maskelenen registry boşluğu

`DrawerTrigger.tsx:11`: `useComponentTheme('DrawerTrigger' as never)` —
registry'de yok. Cast bir tip hatasını sustırıyor, tema-override gerçekten
çalışmıyor. `drawer/types.ts:177-189` declare module bloğunda `DrawerTrigger`
kayıtlı değil.

### 2.5 Çift `data-*` namespace çatışması (Button)

`spar/.../Button/Button.tsx:92-100` zaten `data-disabled`, `data-loading`,
`data-pressed`, `data-autofocus` set ediyor. Wrapper `Button.tsx:35-43`
`data-disabled` ve `data-loading`'i tekrar set ediyor. Spread sırası gereği
wrapper kazanıyor ama tek doğru kaynak yok; Spar yarın `data-disabled`'ı
`data-state="disabled"`'a çevirirse wrapper kopuk kalır.

### 2.6 `forceMount={true}` Drawer'da hardcoded ve dokümantasız

`Drawer.tsx:27` consumer'a görünmüyor; muhtemelen animasyon için ama contract'ta
gerekçe yok.

### 2.7 AccordionHeader runtime guard gereksiz geniş

`AccordionHeader.tsx:16-18` TS tipinin zaten koruduğu `1..6` aralığını
runtime'da bir daha doğruluyor. Public boundary değilse silinmeli (CLAUDE.md
"trust internal code" prensibi).

## 5. Öncelik sıralaması

1. composeRootAttrs API redesign — şu an silent-failure üretiyor, en geniş
   yüzeyi etkiliyor.
2. State-only root tipini sıkılaştır (Drawer & Tooltip) — public API yalan
   söylüyor.
3. DrawerHeader/Body/Footer polymorphic fix — geçersiz HTML üretebiliyor.
4. DrawerPanel.dismissable'ı Spar'a taşı veya en azından consumer
   callback'lerini kompoze hale getir.
5. Test gating — bu adım atlanırsa yukarıdaki düzeltmeler de korunamaz.
6. Button/TooltipContent tema-default fix, TooltipTrigger render-prop ekleme,
   DrawerTrigger registry, slot-registry Drawer ekleme.

## 6. State-only root kararı

Contract takip edildi. Sebep: state-only root için tek bir DOM düğümü yok —
çocuklar (Trigger / Overlay / Panel) farklı yerlerde render oluyor. Bir `<div>`
eklemek wrapper'ı "ince" tutma ilkesiyle çelişir; `display: contents`
erişilebilirlik açısından risklidir. State-driven styling Panel/Overlay
üzerinde, context'ten okunan değerlerle yapılıyor.

## 7. Uygulanan değişiklikler (2026-05-14)

### `composeRootAttrs.stateAttrs` callback'e çevrildi

- `packages/react-spar/src/core/composeRootAttrs.ts` — `stateAttrs` artık
  `(merged: TProps) => Record<string, string | undefined>`. Theme.defaultProps
  artık `data-*` hook'larına otomatik akıyor.
- `packages/react-spar/src/core/theme.ts` — `StateOnlyComponentThemeConfig` tipi
  eklendi (state-only root'lar için sadece `defaultProps` izinli).
- Tüm wrapper'lar tek desene indirildi:
  - `Button.tsx`, `TooltipContent.tsx` — pre-merge destructure bug'u çözüldü
    (variant/appearance/size artık `rest`'ten geliyor).
  - `Accordion.tsx`, `DrawerOverlay/Header/Footer/Panel.tsx`,
    `AccordionItem.tsx` — manuel `rootAttrs` spread'leri kaldırıldı, callback'e
    taşındı.
- Docs şablonu (`docs/component-authoring-contract.md` ve
  `packages/react-spar/docs/coding-standards.md`) yeni API'ye hizalandı.

### TooltipTrigger render-prop children (§2.3)

- `TooltipTriggerProps` artık Spar'dan `children` Pick'liyor →
  `(state: TooltipTriggerRenderProps) => ReactNode` formu consumer'a açıldı.
- Consumer artık ekstra hook olmadan trigger içinden `isOpen` / `disabled` /
  `show()` / `hide()`'a erişebilir.

### DrawerTrigger registry & `as never` temizliği (§2.4)

- `DrawerTrigger` `ComponentThemeRegistry`'ye eklendi
  (`ComponentThemeConfig<DrawerTriggerProps>`).
- `useComponentTheme('DrawerTrigger' as never)` cast'i kaldırıldı, gerçek
  generic ile çağrılıyor → tema-override artık çalışıyor ve consumer provider
  config'inde `DrawerTrigger` set edebilir.

### Polymorphism implementation hizalandı (§2.1)

- `DrawerHeader`, `DrawerBody`, `DrawerFooter` tipleri zaten polymorphic'ti ama
  JSX hardcoded `<div>` render ediyordu (tip-runtime uyumsuzluğu).
- Implementation tipe getirildi: `as` destructure edilip
  `Component = (as ?? 'div') as ElementType` ile gerçek polymorphic render.
- Yakın commit'lerin "polymorphic boundary" yatırımıyla hizalı.

### State-only root kontratı zorlandı (Drawer)

- `DrawerProps`'tan `className` / `classNames` / `slotProps` kaldırıldı.
- `Drawer.tsx` artık `composeRootAttrs` çağırmıyor; tema `defaultProps` doğrudan
  `useComponentTheme('Drawer')` üzerinden tüketiliyor.
- `Drawer` ComponentThemeRegistry'de
  `StateOnlyComponentThemeConfig<DrawerProps>` olarak işaretlendi.
- `apps/docs/docs/components/drawer.api.config.mjs` Drawer root için `className`
  override'ı ve `data-*` listesi temizlendi (artık DOM yok).
- `Tooltip` root zaten state-only desende kalmaya devam ediyor (değişiklik yok).
